# results.city

The Results City homepage. Plain HTML, CSS and a small script, hosted free on GitHub Pages.

- `index.html` — the whole page. Boost cards, copy and form settings live here.
- `css/tokens/` — the Results City design tokens, copied verbatim from the Claude Design handoff. Change colours, type and spacing here.
- `css/site.css` — page components, built on the tokens.
- `js/site.js` — hero player, video modal, form confirmation.

Forms post to FormSubmit and are delivered by email.

To publish a change, commit to `main`. GitHub Pages redeploys in about a minute.
